AGENT GUIDE

Read the catalog or edit a document

Agents can discover starters through the catalog JSON and inspect tool schemas in the OpenAPI document. The MCP endpoint is POST /api/mcp; it accepts JSON-RPC 2.0 over HTTP with protocol version 2025-11-25.

Tools

  • catalog.list returns starter labels, benchmark sources, versions and simplifications.
  • geometry.template returns one bundled GM Studio starter document by ID.
  • geometry.validate checks IDs and references in a supplied GM document.
  • geometry.export returns supported starter XML for geometry or materials.

Browser controls

The application exposes window.openmcStudio with catalog, document, dimension, view, validation and export methods. It registers WebMCP tools when the host browser provides navigator.modelContext.

Data handling and limits

The HTTP tools do not save submitted model documents. Requests have a 500 KB model limit. The endpoint has no authentication because it stores no user state. Do not send private model files unless the agent host and network path are acceptable for that document.

Validation checks document structure only. It does not run OpenMC. The interface preview does not evaluate arbitrary CSG, load BEAVRS, or implement the planned WebAssembly geometry kernel.
