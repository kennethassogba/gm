MODEL GUIDE

What this preview edits

GM Studio keeps an editable JSON document in this browser. The current preview demonstrates a small CSG starter set and repeated rectangular pin universes.

Available starters

Open a fuel pin, schematic PWR 17 × 17 or BWR lattice, or a 19-position hexagonal editing example. Generic PWR, BWR, CANDU, fast reactor and HTGR entries are layout sketches with no reactor design or benchmark status.

View and edit

The canvas sketches the current starter and the XY, XZ and YZ panels derive simple projections from its listed dimensions. It does not evaluate arbitrary OpenMC CSG regions. Crosshair position, selection and radius controls are editing aids for the supported starters.

Undo and redo cover dimension edits and several tree operations. Autosave writes the current document to this browser's local storage. Use the GM JSON export to carry the editor document to another browser.

Import and export

The editor reads a supported subset of geometry.xml surfaces: z-cylinder, x-plane, y-plane, z-plane and sphere. It also reads material definitions from materials.xml. Import does not preserve every OpenMC field, surface type, region expression, lattice orientation, boundary condition, tally or settings file.

XML export is available for the fuel pin and rectangular lattice starters. The hexagonal view is an editing sketch and is not exported as OpenMC XML. The generated Python file reads geometry.xml and materials.xml through OpenMC; it does not define a simulation run.

Every XML export is a starting point. This preview has not run exported files through an installed OpenMC release.

Not in this preview

The planned C++/WebAssembly geometry kernel, evaluated Boolean-region renderer, GPU acceleration, full universe-instance editing, BEAVRS model, transport calculation and export acceptance check are not implemented. BEAVRS, C5G7 and Takeda cards point to their public references; they do not load benchmark models.
