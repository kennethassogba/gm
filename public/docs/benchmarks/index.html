SOURCES & VERSIONS

Benchmark references

These cards link to public specifications or model sources. GM Studio does not package their input files or results.

BEAVRS

Two-cycle, full-core PWR depletion benchmark. Reference version: BEAVRS specification 2.0.2. The public MIT CRPG BEAVRS repository includes specifications, measurements and simulation model sources, including an OpenMC model generator. This preview does not load or edit BEAVRS geometry. The example PWR lattice in GM is a separate schematic component.

C5G7

OECD/NEA multigroup benchmark family. The NEA benchmark page covers the C5G7 MOX benchmark specification (NEA/NSC/DOC(2003)16, 2003). MIT CRPG also maintains OpenMC model scripts for pin, 2D, 3D and additional extension cases. GM's C5G7 cards link to references only. Multigroup compositions, maps, axial zones, control rods and reference results are not bundled here.

Takeda

The OECD/NEA report page identifies the 3D radiation transport benchmarks for simple geometries with void regions (NEA/NSC/DOC(2000)4, 2000), including the Takeda benchmark family. No variant, geometry or result is included in this preview.

Generic layouts

PWR, BWR, CANDU, fast reactor and HTGR cards are generated teaching sketches. They are not reference designs, safety models or benchmark inputs.

Check the linked source and the OpenMC release you plan to use before relying on an imported or exported model.
