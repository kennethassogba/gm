MODEL GUIDE

What this preview edits

GM Studio keeps an editable JSON document in this browser. The preview includes pin and repeated-lattice starters, plus a source-based BEAVRS 2D slice with the published 19×19 core map and one representative 17×17 pin-layout template.

Available starters

Open a fuel pin, schematic PWR 17 × 17 or BWR lattice, a 19-position hexagonal editing example, or BEAVRS. In the BEAVRS slice, choose a map entry, open the representative pin grid, select a fuel pin and edit its radius. Generic PWR, BWR, CANDU, fast reactor and HTGR entries are layout sketches with no reactor design or benchmark status.

View and edit

The canvas sketches the current starter and the XY, XZ and YZ panels derive simple projections from its listed dimensions. It does not evaluate arbitrary OpenMC CSG regions. In the BEAVRS slice, pin-radius edits update the shared OpenMC pin universe and redraw the pin view; the interface labels that shared scope. Per-occurrence pin edits are not available there.

Undo and redo cover dimension edits and several tree operations. Autosave writes the current document to this browser's local storage. Use the GM JSON export to carry the editor document to another browser.

Import and export

The editor reads a supported subset of geometry.xml surfaces: z-cylinder, x-plane, y-plane, z-plane and sphere. It also reads material definitions from materials.xml. Import does not preserve every OpenMC field, surface type, region expression, lattice orientation, boundary condition, tally or settings file.

XML export covers the fuel-pin and rectangular-lattice starters plus the source-based BEAVRS 2D hierarchy. The hexagonal view remains an editing sketch. The generated Python file reads geometry.xml and materials.xml through OpenMC; it does not define a simulation run. OpenMC parsing and transport have not been run in this release.

BEAVRS slice limits

The slice retains the source core map, pin dimensions and a reflective 220–230 cm axial span. One representative pin-layout template and one 3.1% UO₂ recipe stand in for all map entries; assembly-specific loading, baffle materials, enrichment zoning, control rods, burnable absorbers, instrumentation variants and dissolved boron are simplified or omitted. The slice is not a complete benchmark input. Read the source and simplification notes.

Not in this preview

The planned C++/WebAssembly geometry kernel, evaluated Boolean-region renderer, GPU acceleration, per-occurrence BEAVRS editing, complete benchmark fidelity, transport calculation and OpenMC acceptance check are not implemented. C5G7 and Takeda cards point to their public references; they do not load benchmark models.
