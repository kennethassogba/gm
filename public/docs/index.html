Geometry format

Model

GM stores surfaces, Boolean regions, cells, materials, universes and lattices in a local JSON document. Browser autosave and undo/redo keep edits on your device.

Views

GPU rendering reuses repeated geometry. XY, XZ and YZ sections evaluate the same CSG regions. Complex Boolean solids use a voxel mesh for their 3D display; sections and XML retain the original region expressions.

Files

Import geometry.xml and materials.xml, or a .gm.json project. Export both XML files and model.py. Supported surfaces: axis planes, arbitrary planes, spheres and Z cylinders. Rectangular and radial hexagonal lattices are supported.

Settings, tallies, distributed materials and rotated universes are outside the editor format. GM does not run neutron transport.
